# Literature Review: Titanic Survival Prediction
## 1. Kaggle — Titanic: Machine Learning from Disaster
The Kaggle Titanic dataset provides passenger information such as class, sex, age, family relationships, fare, and embarkation port, with `Survived` as the target variable. It also supports feature engineering for survival prediction.
**Source:** Kaggle, *Titanic - Machine Learning from Disaster*
https://www.kaggle.com/c/titanic/data
## 2. Exploratory Data Analysis of Titanic Survival Prediction using Machine Learning Techniques
This IEEE study explores Titanic survival prediction using exploratory data analysis and machine-learning techniques. It highlights the importance of understanding passenger characteristics before building classification models.
**Source: *Exploratory Data Analysis of Titanic Survival Prediction using Machine Learning Techniques*
## 3. Comparative Analysis of Titanic Data Prediction Using Logistic Regression and Support Vector Machine for Enhanced Accuracy
This study compares Logistic Regression and Support Vector Machine for Titanic survival classification. It supports using Logistic Regression as a baseline model for comparing classification performance.
**Source:** IEEE Xplore, *Comparative Analysis of Titanic Data Prediction Using Logistic Regression and Support Vector Machine for Enhanced Accuracy*
## 4. Debiasing SHAP Scores in Random Forests
Loecher's study uses the Titanic dataset to demonstrate potential bias in Random Forest feature-importance measures. It emphasizes careful feature selection and avoiding irrelevant identifier-like variables.
**Source:** Loecher, M. (2024). *Debiasing SHAP scores in random forests*. AStA Advances in Statistical Analysis, 108, 427–440.
## Literature Review Summary
The reviewed sources show that Titanic survival is commonly studied as a binary classification problem. They also highlight the importance of EDA, feature engineering, model comparison, and careful feature selection.
